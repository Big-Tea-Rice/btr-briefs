PO3 weekly profile (daily chart)

Power of 3 read from daily bars: the week's first session is the accumulation range, a sweep of it on session 2 or 3 is the Judas move, and a daily close back through the weekly open sets the week's bias. It only changes when a daily bar closes. Visual note, untested as a rule: not a signal. Tap any tag for its definition.

Reference: PO3 terms
  • ACCUMULATION: the week's first session. Its high and low set the range and its open is the weekly open. Nothing to read until the next sessions test that range.
  • NO SWEEP: sessions 2 and 3 stayed inside the first session's range. No Judas move, so no PO3 read.
  • JUDAS UP: the false move. On session 2 or 3 price traded ABOVE the first session's high. It becomes a bearish week only if a daily bar then closes back inside the range and below the weekly open. Until then the week is undecided.
  • JUDAS DOWN: the false move. On session 2 or 3 price traded BELOW the first session's low. It becomes a bullish week only if a daily bar then closes back inside the range and above the weekly open. Until then the week is undecided.
  • BEARISH WEEK (OHLC): open, high made first (sweep above the first session's range), then a daily close back below the weekly open. PO3 theory expects the rest of the week to distribute lower. Backtest: no edge by itself, and clearly worse when it goes against the 20-day regime.
  • BULLISH WEEK (OLHC): open, low made first (sweep below the first session's range), then a daily close back above the weekly open. PO3 theory expects the rest of the week to distribute higher. Backtest: no edge by itself, and clearly worse when it goes against the 20-day regime.
  • SEEK & DESTROY: both sides of the first session's range were swept before any close back through the weekly open. Stops on both sides were taken; there is no directional read this week.
Reference: Markov regime tag
  • UP / DOWN / SIDE = the last 20 sessions moved up more than the band, down more than the band, or less than the band either way. The band is dynamic: 3 x ATR14 (about one 20-day standard deviation), so it adapts to each market's volatility.
  • Signal = chance the next 20-day window is up minus the chance it is down, from past cases of the same state (-1 to +1; near 0 = no lean; under 5 cases = ignore).
  • With / against / neutral = whether a PO3 bias points the same way as the regime. Backtest: PO3 against the regime hit 29% vs 34% control, so treat 'against' as a reason to skip. 'With' added nothing.
  • Full guide: the Regime tab (Reference: how to read the Markov regime).

Summary

Reference: how to read the Markov regime
  • Regime = today's state from the last 20 days' move against a dynamic band of 3 x ATR14 (about one 20-day standard deviation), so the band widens and narrows with each market's volatility. UP: above the band. DOWN: below the negative band. SIDE: in between. Each card shows its band. Rows without full price bars keep a fixed band.
  • Odds bar (green / grey / red) = the chance, from history, that tomorrow's regime label is up / sideways / down. It forecasts the label, not whether tomorrow closes higher.
  • Signal = P(up) minus P(down), from -1 to +1. Near 0 = no lean. About 0.3 or more either way = a lean, if the sample count is decent.
  • Samples: how many past cases of this state the odds rest on. Under 5 is marked thin: ignore it.
  • SIDE with a big signal (e.g. SIDE, +0.6): this state has usually turned into UP next. Read it as a regime likely to flip.
  • Rates: for yields, UP = yields rising = bonds selling off. For Treasury futures (ZT/ZF/ZN/ZB), UP = bond prices rising.

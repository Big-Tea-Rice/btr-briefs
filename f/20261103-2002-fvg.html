Summary

Reference: how to read the Markov regime
  • Regime = today's state from the last 20 days' move against a dynamic band of 3 x ATR14 (about one 20-day standard deviation), so the band widens and narrows with each market's volatility. UP: above the band. DOWN: below the negative band. SIDE: in between. Each card shows its band. Rows without full price bars keep a fixed band.
  • Odds bar (green / grey / red) = the chance, from history, that tomorrow's regime label is up / sideways / down. It forecasts the label, not whether tomorrow closes higher.
  • Signal = P(up) minus P(down), from -1 to +1. Near 0 = no lean. About 0.3 or more either way = a lean, if the sample count is decent.
  • Samples: how many past cases of this state the odds rest on. Under 5 is marked thin: ignore it.
  • SIDE with a big signal (e.g. SIDE, +0.6): this state has usually turned into UP next. Read it as a regime likely to flip.
  • Rates: for yields, UP = yields rising = bonds selling off. For Treasury futures (ZT/ZF/ZN/ZB), UP = bond prices rising.
  • How to use it: context, not a trigger (no standalone edge in the 26 Sep test). One tested use: skip a PO3 weekly read that goes against the regime (29% hit vs 34% control).
  • Chart tags vs this report: both use the 3 x ATR14 band. The chart tags are calculated on cash-index bars with a 20-day-ahead window; this report uses futures bars and next-day odds, so a label can still differ slightly.

Method and data

Analytical only, no execution. Regime = 20-day cumulative-move Markov with a dynamic band of 3 x ATR14 (about one 20-day standard deviation, shown per row; rows without OHLC keep the fixed band: Equity ±5%, FX ±2%, Rates ±5%, Crypto ±10%) → Up/Down, else Sideways; signal = P(up)−P(down) next day, honest stride-sampled matrix ("thin" = under 5 past samples of the current state; treat as low confidence). FVG = open 3-candle daily gaps, last 200 bars; open until a daily close beyond the far edge (matches Nephew_Sam). All rows: TradingView daily bars, full history (futures = front-month continuous incl. overnight session; FX = OANDA spot; yields = TVC with OHLC). Regime uses all history loaded (bar count per row). No fallback feed: a row TradingView cannot serve shows as unavailable. Rates — yield rows: UP = yields rising = bonds selling off; US Treasury futures rows (ZT/ZF/ZN/ZB) are price: UP = bond price up = yields down. Yield regimes only use history after the last time the yield was ≤0.25% (DE/JP/UK went negative 2016-21), so those rows rest on fewer samples. FX = spot._
